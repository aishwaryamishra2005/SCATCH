# 🛒 E-Commerce Website

A full-stack e-commerce web application built using **Node.js, Express.js, MongoDB, EJS, and JavaScript**. The application provides separate authentication and login functionality for users and administrators, with dedicated interfaces for managing the shopping experience.

## 🚀 Tech Stack

- **Frontend:** HTML, CSS, JavaScript, EJS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** Json Web Tokens
- **Templating Engine:** EJS

## ✨ Features

### 👤 User

- User registration and login.
- Secure authentication.
- Dedicated user interface.
- Access to the e-commerce application.

### 🔐 Admin

- Separate admin login.
- Dedicated admin dashboard.
- Admin-side access to application management.

### ⚙️ General

- Dynamic pages using EJS.
- Backend functionality using Express.js.
- MongoDB database integration.
- Server-side routing and request handling.
- Structured application architecture.

## 🔑 Authentication

The application provides separate login interfaces for users and administrators, allowing different types of access based on their roles.

## 🎯 Project Objective

The main objective of this project is to understand and implement full-stack web development concepts, including:

- Client-server architecture.
- RESTful routing.
- Database connectivity and operations.
- Authentication and authorization.
- Dynamic rendering using EJS.
- Backend development using Node.js and Express.js.
